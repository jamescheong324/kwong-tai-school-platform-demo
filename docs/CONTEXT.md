# 廣大中學智慧管理平台 Demo

本機可點的構想稿，用來走通校長出差看校況、班級交接、家長會調檔這三條故事。不是上線產品，也不是 Phase 1 MVP。

## Language

**Demo**：
本機 localhost 開啟的可點 web 構想稿，資料全是假的。
_Avoid_: 產品, MVP, 系統（當它其實只是構想稿時）

**校長駕駛艙**：
校長每天打開後看到的今日校況：出勤、缺席、遲到、教師請假／公幹／會議、出勤偏低班級。排課、升學、招生這類不是每天變的，不放在這裡。
_Avoid_: 首頁, Dashboard, 模塊總覽

**班級 360**：
一個班的縱向檔案：現況、歷任班主任、學生名單，用來交接與評選，而不是當天點名表。
_Avoid_: 班級頁, 點名冊

**學生 360**：
一個學生跨學年的完整記錄，家長會時好壞都有東西可指。
_Avoid_: 學生檔案（太像學籍行政表）, profile

**必經路徑**：
唯一必須點得通的故事線：校長駕駛艙 → 出勤異常班級 → 班級 360 → 某學生 → 學生 360 的多年趨勢。
_Avoid_: 完整功能, 全站導航

**假資料**：
寫死在前端的化名學生、班級與數字，用來讓畫面像在運作。
_Avoid_: 真實數據, 後端

**今日異常**：
校長駕駛艙上出勤偏低的班級入口，從這裡走進必經路徑。
_Avoid_: 警告, alert, 異常清單（當它其實只是進班級 360 的門）

**排課**：
先設各班每科週節數與教師不可排時段，再自動排出課表。同一班點兩格可對調。
_Avoid_: 教務系統, 全校教師下拉

**科組資源**：
歸屬學校而非個人的教案、課件、試題，教師離職後仍留在科組。
_Avoid_: 個人雲端, 老師自己的資料夾

**升學追溯**：
依年份與院校查出學生、原班、導師，用來回答「誰帶出這批人」。
_Avoid_: 升學率報表（當你其實要的是個案關聯）

**招生學位**：
各年級／班還剩多少個學位。
_Avoid_: 報名系統

**策略分析**：
點一條校策問題，畫面只留下這一條的推行前後對照。遲到還能拆到年級。分析留在本機。
_Avoid_: 策略成效, 政策簡報, 把多條答案堆在下面
