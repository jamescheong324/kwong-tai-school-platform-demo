# 初步需求訪談會議紀要

**會議性質：** 初步需求訪談  
**訪談對象：** 廣大中學  
**試點學校：** 廣大中學  
**核心議題：** 學校「智慧管理」與「智慧教學」整合平台之可行性與落地方向  
**文件狀態：** 初稿整理

---

## 一、會議背景與核心觀點

與會者指出，澳門多數學校急需一套能**打通各類數據、減少人工重複輸入、支援管理決策**的整合系統。「學生管理」並非僅指學生，亦涵蓋教師（班主任、持續進修、職涯發展等），本質是建立**全校師生職員數據的統一調用與長期沉澱機制**。

現況痛點集中在：

- 數據分散於多個系統或 Excel，**碎片化、非實時、難互通**
- 調閱資料需人工搬運、重新整理，**繁瑣且易出錯漏**
- 管理決策多依主觀印象，**缺乏可驗證的數據支撐**
- 優秀教學成果隨教師離職而流失，**未形成學校資產**

---

## 二、核心需求摘要

### 1. 數據互聯互通（最高優先）

| 維度 | 需求說明 |
|------|----------|
| **縱向** | 學生／教師／班級的歷年完整記錄，可隨時間追溯成長軌跡 |
| **橫向** | 品行、成績、身心健康、培訓、獲獎、升學等指標可交叉查詢 |
| **實時** | 出勤、請假、公幹、上課狀態等可即時掌握，不受時空限制 |
| **一次輸入、多方共享** | 減輕班主任與教師重複填報負擔 |

### 2. 管理端功能需求

- **班級交接**：新老師接手班級時，可取得該班完整歷史數據
- **師生個別化檔案**：與家長會面時可即時展示多年記錄（欠交功課、獲獎、品行等）
- **教師評估依據**：培訓紀錄、獲獎、班主任成效等，支援任用與職位分配決策
- **升學數據追溯**：例如查詢某年考入特定院校的學生及其導師，一鍵拉出關聯數據
- **策略成效驗證**：推行新政策後，可透過成績、遲到率等指標即時評估效果
- **招生支援**：即時查詢年級／班級剩餘學位，無需逐一登入不同平台
- **報表與走勢**：管理者可透過 App 隨時調閱報表與動態趨勢

### 3. 教學端功能需求

- 配合**智慧教學**及各學科**科組資源**整合
- 教學資源應歸屬**學校**而非個人，形成類似企業知識庫的校本資產
- 教師離職後資源仍留存，降低新老師交接落差

### 4. 權限與安全

- 分級權限：校長（全校）、主任（分管範圍）、教師（相關班級／科目）
- 確保敏感數據安全，同時滿足各層級管理需要

---

## 三、應用場景舉例

1. **班主任與家長會面**：即時調出學生多年完整記錄，好壞皆有數據佐證
2. **校長出差期間**：仍可查看每日出勤率、請假紀錄、教師即時狀態（上課／公幹等）
3. **評選優秀班長**：依班級管理記錄、身心健康、成績等多維指標，而非主觀印象
4. **教師任用決策**：數據顯示某教師班主任成效不佳，可調整委任；新策略推行後以數據驗證成效
5. **升學追溯**：查詢特定升學案例及其導師、班級歷史，支援教學與管理分析

---

## 四、澳門本地落地考量

### 現況挑戰

- 澳門學校情況特殊，須以**「貼地」**方式落實，不能照搬外地方案
- 部分資料仍為**紙本**，需實地處理與數位化
- 現有多為**分散系統**，關鍵在於**對接整合**，而非單純數據量問題
- 小規模學校（如德明等）人均成本高，整合需求更迫切

### 市場規模

- 澳門共約 **68 間私校 + 8 所公校**，具規模化（Scalable）潛力
- 本地市場雖小，但學校願意投入資源，**供應商能否滿足實際需求**是關鍵

### 業界參考

- 訪談中提及培正中學等學校現況，作為同類需求之橫向比較
- 早年本地已有學校系統開發經驗（如勞校相關案例），證明本地技術服務學校具可行性
- 現今核心問題已從「有無系統」轉為「**系統能否打通、數據能否延續**」

## 五、商業與推廣策略（訪談觀點）

| 項目 | 建議方向 |
|------|----------|
| **試點學校** | 以**廣大中學**為示範窗口，雙方探討如何連接現有分散系統 |
| **突破口** | 先做出口碑與實證成果，不宜只著眼收費；價格可具競爭力，但須見成效 |
| **口碑效應** | 一間學校成功案例可帶動其他學校前來體驗 |
| **教青局方向** | 需了解是否有校本計劃、AI 或教育教學管理專項中的「先行先試」「先導計劃」等補貼或資助 |
| **政策契合** | 教青局亦希望數據可共享，有實證案例將具示範價值 |

## 六、技術與產品定位

**平台定位：** 不僅是單一功能系統，而是學校的**核心數據庫與管理決策支撐平台**

**開發原則：**

1. 站在本地使用者角度設計
2. 根基在於「**互通**」與「**實時**」
3. 數據具**持續性與沉澱價值**，支援學校長期發展
4. 智慧管理與智慧教學須**打通縱橫關係**

**整合範圍（初步）：**

- 學生管理、品行、成績、身心健康
- 教師培訓、獲獎、請假、公幹、任課狀態
- 班級管理、升學、招生
- 科組教學資源
- 各類報表與動態走勢

## 七、待釐清事項

1. **廣大中學現有系統清單**：目前使用哪些平台／系統？數據格式與接口情況？
2. **優先整合模組**：管理端與教學端何者先行？哪些痛點最急迫？
3. **教青局資助渠道**：校本計劃、AI 專項、先導計劃的申請條件與時程
4. **紙本資料範圍**：哪些資料仍需人工錄入或掃描？
5. **權限與合規**：個人資料保護、教青局數據共享政策要求
6. **與現有供應商關係**：是否需與現有系統廠商協作對接？

## 九、會議結論（初步）

與會者認為，澳門各校正處於**數據斷層**階段，Excel 與多系統並存導致管理效率低、決策缺乏依據。**廣大中學**願意作為**試點學校**，若能在「智慧管理」與「智慧教學」整合、數據縱橫打通、實時調閱、校本資產沉澱等方面取得實證成果，不僅能解決本校痛點，亦有潛力成為全澳學校的示範案例，並與教青局推動教育數據共享的長遠方向契合。

**下一步重點：** 以廣大中學為切入點，盤點現況、設計整合路徑、建立先導示範窗口，同時評估政府資助與商業推廣模式。
